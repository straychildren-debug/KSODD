# КСОДД — конструктор схем

Бесплатный редактор схем участков дорожного движения (дороги, перекрёстки, тротуары, газоны, здания, разметка, переходы, парковки, светофоры). Работает в браузере, без установки и без интернета.

## Запуск

Откройте `index.html` двойным щелчком (Chrome / Edge / Яндекс.Браузер).

Или через локальный сервер:

```bash
python -m http.server 8765
```

и откройте http://localhost:8765.

## Как работать

1. «Пример» на ленте — готовая схема перекрёстка, чтобы посмотреть возможности.
2. **Дорога** — щёлкайте точки оси, двойной щелчок завершает. Число полос, ширина, тротуары, газон, разметка — в панели свойств справа.
3. **Перекрёсток** — щелчок рядом с пересечением двух дорог строит площадку со скруглёнными бордюрами.
4. **Здание / Газон / Площадка / Асфальт** — протяните прямоугольник или щёлкайте вершины. Цвет заливки меняется в свойствах: готовые образцы (жилое, общественное, торговое, школа, нежилое…) или любой свой цвет. У парковки так же меняется цвет подсветки (например, фиолетовый для платной).
5. **Переход** — щелчок по дороге; **Парковка** — протяните вдоль бордюра.
6. **Знак** — выберите знак в палитре справа и щёлкните место стойки. Пока стойка выделена, щелчок по знаку в палитре добавляет его (или табличку 8.x) на эту стойку. Пакет знаков отодвигается за ручку, направление — Q/E. Сверху палитры — готовые наборы на одну стойку (платная парковка 6.4 + 8.8 с временем, номером зоны, способом постановки; начало и конец зоны платной парковки 5.29 / 5.30; парковка для МГН). Есть 2.1, 2.4, 2.5, 3.27–3.30, 5.19.1/2, 5.27–5.30, 6.4, таблички 8.1.1, 8.2.1–8.2.6, 8.5.4, 8.6.1, 8.8, 8.17 и табличка со своим текстом. У парковки можно задать места для МГН — на них наносится разметка 1.24.3.
7. **Подложка** — загрузите скриншот карты и откалибруйте масштаб по известному расстоянию.
8. **Экспорт** — PNG (с выбором масштаба 1:200…1:2000 и dpi) или SVG.

Схема автоматически сохраняется в браузере; «Сохранить» скачивает файл `.ksodd.json`, который можно открыть снова.

## Структура

- `js/geom.js` — геометрия (сдвиг линий, сглаживание, скругление углов, пересечения)
- `js/signs.js` — каталог дорожных знаков (векторные изображения)
- `js/render.js` — отрисовка объектов в SVG
- `js/app.js` — редактор: инструменты, мышь, свойства, файлы, экспорт
